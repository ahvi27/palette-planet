# 🎨 Palette Planet

A colorful palette generator for developers, designers, and curious
creators. Discover color combinations for websites, brands, portfolios,
and other creative projects.

## Features

- Generate five-color palettes
- Choose from five moods:
  - Dreamy pastels
  - Earthy escape
  - Bright energy
  - Ocean breeze
  - Anything goes
- Lock favorite colors while generating new ones
- Copy individual hex codes
- Copy the whole palette as CSS variables
- Generate a palette using the Space key
- Responsive desktop and mobile layouts
- Reduced-motion support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Clipboard API

Everything is contained in one HTML file. No installation, framework,
account, or API key is required.

## Getting Started

1. Download or clone the repository.
2. Open `index.html` in your browser.
